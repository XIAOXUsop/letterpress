# 你拿到什么

完整功能清单。**没有的也列在后面**——一个模板的诚实程度就看这一栏。

| | |
|---|---|
| 📝 **写作** | Markdown / **MDX**，草稿在 `dev` 下可见、构建时自动排除；置顶、标签；文章占用 `/about/` 等系统路由时构建失败 |
| 🔍 **搜索** | Pagefind 全文检索，构建期建索引，零后端；按 `/` 可从任意页面进入搜索，并避开输入区域。**零 JS 依赖**——不搜索就不加载索引 |
| 🧭 **导航** | 目录（锚点与渲染器逐字对齐）、小节永久链接、上一篇/下一篇、分页、按年归档、标签索引 |
| 🖼️ **配图** | 封面图可选；**不提供也有**——由 slug 确定性生成几何封面，与站点设计同源 |
| 🔗 **分享** | 1200×630 分享图（PNG，由构建生成）、Open Graph、Twitter 卡片、JSON-LD |
| 📡 **订阅** | 全站及**每个标签**的 RSS 全文输出（含分类、作者与 Atom self-link）、sitemap、robots.txt |
| 🌏 **中文** | 行高 1.75、标题字重按中文字体特性选、行宽 `34em`、`text-autospace` 中西文自动间距、中文不用斜体 —— 详见 [中文排版取值](cjk-typography.md) |
| ♿ **无障碍** | 跳转链接、100% 可见焦点、`prefers-reduced-motion`；**对比度有自动化测试**（解析 `tokens.css` 逐对验算，亮暗双模式） |
| 🤖 **给机器** | **文章与知识库条目**有 `.md` 孪生文件并可一键复制；`Accept: text/markdown` 直接返回 markdown；`content.ndjson` 全量导入；`content-manifest.json` 按 hash 增量同步；零依赖同步器负责删除传播、损坏修复与失败回滚；另有 `llms.txt` 与 `llms-full.txt` —— 详见 [内容协商](content-negotiation.md)、[全量导出](content-export.md)、[内容清单](content-manifest.md)与[内容镜像同步](content-sync.md) |
| 🧠 **知识层** | 用 `[[方括号]]` 互链的独立知识库；断链**会让构建失败**；**有问题时**打印体检报告（干净构建不打印） |
| 🌗 **主题** | 三态（跟随系统 / 亮 / 暗），无闪烁（恢复脚本在 `<head>` 同步执行） |
| 📦 **交付** | 纯静态，零外部 JS 文件；提供去导航、代码不裁切的打印 / PDF 样式；字体只含拉丁子集 100 KB |
| 🚀 **部署** | Cloudflare Pages / Netlify / Vercel / 任何静态托管；三个平台的内容协商垫片已写好 —— 详见 [部署](deploy.md) |

## 没有做的

| | |
|---|---|
| ❌ 数学公式 / 流程图 | 接 KaTeX / Mermaid 即可，本项目不预装 |
| ❌ 多语言 | 单语言。`lang` 可配，但不含 i18n 路由 |
| ❌ 图片灯箱 / 页面转场 | 接 PhotoSwipe 之类的成熟方案 |
| ❌ 评论 | 接 giscus |
| ❌ 定时发布 | **刻意不做**，理由见下 |

### 为什么「定时发布」明明能做却不做

它会让「是否发布」依赖**构建时刻**，于是同一份源码在 UTC 与 UTC+8 构建出不同产物：
本地能看到、CI 看不到，或者反过来。而失败形态是文章静默消失、引用它的
`[[链接]]` 变成断链。

代价是破坏**构建可复现**与**跨机器一致**两个契约。而 `draft: true`
已经覆盖了「还没写完」这个主要场景。**做不到的事不该留着**——这个功能被删掉了，
不是没做。
