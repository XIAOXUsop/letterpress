# 设计取舍

> 这些决定都是有代价的。写下来是为了让后来的人能推翻它们——但得先知道当初为什么。

## 为什么不用 Tailwind

这套版式靠精确的网格与字体控制，手写 CSS + 自定义属性 + `@layer` 能完全控住，
依赖面也更小。一个博客模板要活十年，**依赖少是优势**。

代价是写样式要自己管命名与层级。本项目的做法是三层令牌
（primitive → semantic → component），组件只引用 semantic 层，
见 `src/styles/tokens.css` 顶部的说明。

## 为什么字体只自托管拉丁子集

中文字体单文件 5–20 MB，哪怕做了子集化，一个博客站也不该为此付出首屏时间。
而中文系统字体质量本身就很好。

配合 `unicode-range`，中文自动落到系统字体（苹方 / 雅黑 / 思源黑体）——
**这不是回退，是分工**。详见 [中文排版取值](cjk-typography.md)。

## 为什么内容协商的转换在构建期做

运行时转换意味着每次请求都要现算；静态产物直接命中 CDN 缓存：
**零运行时成本、零冷启动、源站挂了也不受影响**。

代价是产物里多了一份 `.md`（本项目 11 个孪生文件）。

## 为什么体检失败会让构建中止

**一个不会失败的检查等于没有检查。**

这条原则贯穿整个仓库，也解释了为什么会有 `npm run verify` 的 201 项契约、
`verify:base` 的六类载体扫描、以及内容发布探针。每一次都是因为**踩过**
才补的——具体踩了什么，写在对应脚本的注释里。

反过来也成立：**一条会无缘无故变红的检查，同样不值得信任。**
所以断言都尽量从产物里推导，而不是写死路径（见 `[4c]` 与 `[4d]` 两节）。

现在 `npm run verify:reproducible` 会先禁止生产源码直接读取构建时钟，再分别在 UTC
与 America/Los_Angeles 做干净构建，把 Astro 页面、RSS、图片、Markdown、内容清单、全量导出
和 Pagefind 索引逐文件比较 SHA-256。可复现性因此覆盖跨年时钟泄漏与跨时区漂移，
是一条能让 CI 失败的契约，不再只是设计目标。

## 为什么配色刻意避开了「米色 + 衬线体 + 鼠尾草绿」

那是 2026 年新的 AI 默认值——看起来「有品味」，但换掉的只是默认值本身。
同样避开的还有紫蓝渐变。

瑞士国际主义（一个强调色、网格、几何、全直角）是一个**有据可依**的选择，
不是反射：强调色取自 International Klein Blue `#002FA7`，它本身就是那个年代的
产物，与风格同源。暗色模式下换成提亮的 `#6b91ff`——原色在黑底上只有约 2:1，
读不了。

## 为什么没有任何外部 JS 文件

首页与内容页的 JS 请求数是 **0**（实测：全站 HTML 里 `<script src>` 计数为 0）。
需要脚本的地方只有三处——主题切换、代码复制、搜索热键——都是内联的，合计 2.5 KB。

唯一的例外是搜索页：那里的内联加载器会从**站内同源**取 Pagefind。
**「没有外链 JS」与「不加载 JS」不是一回事**，量出来的数见
[竞品对照](compare.md#关于站内-js这一行)。

> ⚠️ **2026-09-24 修正**：这一行原先写「实测 gzip 146 KB」。
> **那个数在当前环境已无法复现**——pagefind 版本没变（1.5.2），
> 而产物结构对不上（17 个文件 → 6 个）。
> README 的「站内 JS」一行已经改成可复现的口径并记了这次改动。
>
> 现在的可复现数字（`npm run measure` 的口径，2026-09-24 补了 gzip 那一行）：
> **6 个 js、未压缩 431 KB、gzip 合计 105 KB**（gzip level 9）。
>
> 其中「访问者真正会加载 5 个、gzip 93 KB」那个更窄的口径
> **需要浏览器网络面板才能确认**——Node 里量不出来，
> 因为 `pagefind.js` 内部按需加载哪些 UI 组件取决于页面上的配置。
> **`measure` 给的是可复现的上界**，窄口径是实测值，两者不是一回事。

代价：内容协商返回 markdown 时不会被这些内联样式污染；代价的另一面是
搜索页需要 CSP 允许 `unsafe-eval`（原因见 [命令行](cli.md)）。

## 为什么「定时发布」被删掉了

它与「构建可复现」直接冲突：同一份源码在 UTC 与 UTC+8 会构建出不同产物，
而失败形态是文章静默消失、引用它的链接变成断链。

**不是修不好，是代价算不过来。** 详见 [功能清单](features.md#为什么定时发布明明能做却不做)。
