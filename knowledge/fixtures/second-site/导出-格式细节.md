# 导出

## §1 逐行格式

NDJSON 的「ND」指**每行一个 JSON 值**，
所以它能被逐行处理，而**不能整体 `JSON.parse`**。

## §2 字段与 manifest 的一致性

同一次构建里，NDJSON 的每条记录与 manifest 里对应条目**必须一致**。
不一致会让「先导入再增量」这条路径**静默丢内容**。

## §3 为什么不用 zip

zip 省流量但**不能流式消费**。对「一次请求边下边处理」的场景，
流式比压缩重要。
