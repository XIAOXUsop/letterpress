一个开源个人博客主题。Astro 7 + TypeScript，纯静态，零后端，MIT。

## 它想解决的三件事

**一、中文排版普遍做错。** 行高、字重、行宽直接套西文的值，
[[中文排版]] 里有完整的对照表。

**二、对 AI agent 不友好。** 静态博客没法做 [[内容协商]]，
因为托管平台不解析请求头。项目带了三个平台的边缘函数实现。

**三、知识会腐烂。** 加一层 [[LLM 知识库]]，把文章从「流」变成「网」，
并且把机械可判定的检查做成能进 CI 的 lint。

同一原则也用于构建本身：`npm run verify:reproducible` 会禁止生产源码读取构建时钟，
并在两个时区完整构建，逐文件比较 Astro 与 Pagefind 的全部产物，
而不是靠「代码看起来确定」来判断。

## 不做什么

- **不做生成器**。生成器赛道拥挤且被托管平台生态锁死。
- **不做数据库**。内容就是文件，躺在你的仓库里。
- **不用 Tailwind**。瑞士风格需要精确的网格与字体控制，
  手写 CSS + 自定义属性 + `@layer` 更直接，依赖面也更小。
  一个博客模板要活十年，这是优势。
- **不把 llms.txt 当卖点**。它的实际效果被严重高估，数据见 [[内容协商]]。

## 技术选择

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | Astro 7 | 内容优先，默认零 JS，AI 爬虫不执行 JS |
| 样式 | 手写 CSS + `@layer` | 精确控制，零依赖，见 [[设计令牌]] |
| 字体 | 自托管拉丁子集 + 系统中文字体 | 中文字体 5–20 MB，不值得 |
| 内容协商 | 构建期孪生 + 边缘函数 | 转换零运行时成本 |
